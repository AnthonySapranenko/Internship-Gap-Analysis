# Sample internship postings

Real internship descriptions used as test data for the analysis engine (Phase 3) and for
evaluation (Phase 8).

- One posting per file, saved as plain text: `company-role.txt`, for example `acme-swe-intern.txt`.
- Paste the description as it appears. Don't clean it up, because messy input is part of the test.
- Remove anything personal, such as recruiter names, emails, or phone numbers.
